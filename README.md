# Tic-Tac-Toe

A classic two-player Tic-Tac-Toe game built with vanilla JavaScript.  
**Live demo:** [https://tic-tac-toe-jet-one-87.vercel.app/](https://tic-tac-toe-jet-one-87.vercel.app/)

## Features
- Two-player turn-based gameplay
- Custom player names and mark selection (X or O)
- Automatic win/tie detection
- Persistent score tracking during the session
- Clean, responsive UI with dark-themed setup form

## How to Play
1. Click **START**.
2. Enter names and choose marks for both players.
3. Click **PLAY**.
4. Take turns clicking on the grid to place your mark.
5. First to get three in a row (horizontal, vertical, or diagonal) wins!
6. Use the **Reset** button to clear the board while keeping scores.

## Setup
1. Clone the repository:
   ```bash
   git clone git@github.com:simeon-dev1/tic-tac-toe.git
   cd tic-tac-toe
```

2. Open index.html in your browser (or use a local server like Live Server).
